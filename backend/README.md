# AI Intelligence Studio - Backend

FastAPI backend service powering multi-modal AI capabilities using Hugging Face models.

## Structure
- `app/core/`: Configuration and settings
- `app/api/`: REST API endpoints and routes
- `app/schemas/`: Pydantic data schemas
- `app/services/`: Isolated AI capability services
- `app/models/`: Internal data models
- `app/utils/`: Helper utilities
